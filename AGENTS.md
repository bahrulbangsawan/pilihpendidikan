# Agent Guidelines

## Before Coding

- Read the root `CLAUDE.md` for architecture, commands and conventions
- Read `.claude/CLAUDE.md` for code quality standards (Ultracite rules via Biome)
- Read `DESIGN.md` and `TYPOGRAPHY.md` before touching UI
- Check `openspec/changes/` for active changes that may conflict with your work

## Key Paths

| Path | Purpose |
|------|---------|
| `apps/cv/src/components/cv-generator.tsx` | CV editor shell, toolbar, MCP dialog, `MCP_API` |
| `apps/cv/src/components/templates/` | CV templates (`*-preview.tsx` + `*-pdf.tsx` pairs) |
| `apps/invoice/src/components/invoice-generator.tsx` | Invoice editor shell, `MCP_API` |
| `apps/invoice/src/data/wilayah/` | Indonesian region tables (generated by `apps/invoice/scripts/parse-wilayah.ts`) |
| `apps/portfolio/src/components/portfolio-generator.tsx` | Portfolio editor shell, `MCP_API` |
| `apps/portfolio/src/components/portfolio-data-model.ts` | Locked ADA portfolio data model and limits |
| `apps/*/src/styles.css` | Warp design tokens (`@theme inline`, parity-checked) |
| `apps/*/src/i18n/locales/{en,id}.json` | UI copy, English and Indonesian |
| `apps/*/public/{robots.txt,sitemap.xml,llms.txt}` | Crawler and agent discovery files |
| `packages/ui/src/` | `@rulisme/ui` primitives (`ui/`, `form/`, `reui/`, `lib/`) |
| `packages/config/` | `tsconfig.base.json`, `motion.css` |
| `scripts/` | Typography lint and parity checks |

## Workflow

- Run `bun x ultracite fix && bun run check` before committing
- Run `bun run build` after changing `packages/ui` so the apps resolve the new `dist/`
- Use `openspec validate <change-id> --strict` after writing proposals
- UI primitives live in `packages/ui` — check existing components before creating new ones
- Keep each `*-preview.tsx` and its `*-pdf.tsx` in sync by hand; they are separate renderers

# This is NOT the Turborepo you know

Turborepo configuration, task behavior, and CLI commands can vary between installed versions and may differ from your training data. Resolve the `turbo` package from this file's directory or relevant workspace; in monorepos, it may not be visible from the repository root. For example, run `node -p "require.resolve('turbo/package.json')"` from a workspace that depends on `turbo`.

Read `docs/README.md` inside that installed package first, then read the relevant pages from its `docs/` directory before changing Turborepo configuration or commands. Heed deprecation notices. These bundled docs match the installed package version and are available without network access.

This block is written and re-added by `turbo` before repository-scoped commands when an AI agent is detected. In the Turborepo source repository, its template is defined in `crates/turborepo-cli/src/cli/agent_guidance.rs`. Removing the managed block while updates are enabled means a later qualifying invocation will add it again. Set `"agentGuidance": false` in the root `turbo.json` or `turbo.jsonc` to opt out; this does not remove an existing block. Keep the block committed with your work to avoid an uncommitted change on the next agent invocation.
