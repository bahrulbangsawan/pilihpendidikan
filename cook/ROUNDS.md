## Decisions

- 23:45 Font: Geist (OFL) for CursorGothic, because a width test of 14 free families on cursor.com's own strings put Geist at 0.34% mean width error with an identical cap height (`cook/refs/fonttest/`). Mono: Geist Mono for berkeleyMono.
- 23:50 Keep the token and utility NAMES (`type-*`, `weight-*`, `ink`, `pane`, `primary`…) and remap their VALUES to cursor.com, because 300+ files use them; retire ornaments (`graph-paper`, `diamond`, `rail-nodes`, `hatch`, lips, offset shadows) as no-op utilities so markup migrates without breaking.
- 23:50 Type roles mapped onto cursor.com's scale (`type-sm` 14 = body, `type-base` 16 = subtitle, `type-md` 22 = title, `type-md-lg` 26 = display), plus two new roles `hero` (72) and `headline` (36). All weight 400.
- 23:55 `muted-foreground` stays at Cursor's exact 60% in dark (6.25:1, AA); in light it would have needed 66%, moot after dark-only.
- 00:00 Hub keeps its product rule "each live service linked exactly once": hero, header and closing CTA link to `#tools`, each feature card links its builder once.
- 00:00 No Cursor content: no testimonial wall (would be fabricated quotes); replaced with six truthful feature cards. No customer-logo strip; replaced with eight feature tiles.
- 00:05 Feature card media are screenshots of our own builders (`apps/home/public/shots/*.webp`, regenerated by `cook/harness/shots.sh`).
- 00:10 Hero backdrop: our own painted landscape in SVG (turbulence displacement, mottling, grain), not Cursor's painting.
- 00:12 Dark only (user): `:root` = cursor.com dark; `.dark` kept as an alias; theme toggles and next-themes switching removed in every app (`forcedTheme="dark"`).
- 00:15 Sidebar token = card colour (#1b1913), measured from cursor.com/docs dark.
- 00:20 Each agent uses its own agent-browser session (`AGENT_BROWSER_SESSION`), because the shared default session mixed pages between agents.

- 00:56 Jobs removal scope: the dashboard (`apps/jobs`) only. The `/api/v1` automation routes, the `pilih-jobs` CLI and the scraper stay, because deleting backend features is far riskier and harder to undo than hiding them, and the request names the jobs UI. Mock-api fixtures stay too.
