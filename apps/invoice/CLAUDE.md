# apps/invoice — Invoice Builder

TanStack Start (SSR) app that builds invoices and exports them as PDF or JSON,
with Indonesian region (wilayah) address data. Consumes `@rulisme/ui`.
Deployed to Cloudflare Workers via `@cloudflare/vite-plugin` as
`invoice-pilihpendidikan` on `invoice.pilihpendidikan.com`.

Workspace-wide rules (commands, conventions, typography) live in the root
`CLAUDE.md`, `TYPOGRAPHY.md` and `DESIGN.md`; proposals go in the root
`openspec/` (prefix change ids with `invoice-`).

## Commands

- `bun dev` — Vite dev server on port **4004**
- `bun run build` — `wrangler types` + `vite build`; `bun run preview`
- `bun run test` — Vitest (`src/components/invoice-form-utils.test.ts`)
- `bun run lint` — Biome (`biome check .`); `bun run format` — Biome autofix
- `bun run typecheck` — `wrangler types` + `tsc --noEmit`
- `bun run deploy` — `wrangler deploy` (owner approval required)

## Structure

- `src/router.tsx` + `src/routes/`: `__root.tsx` (head, hreflang), `-root-shell.tsx` (document shell, ThemeProvider, i18n), `-root-helpers.ts` (JSON-LD), `index.tsx` (EN), `id.tsx` (ID), `$.tsx` (catch-all 404). `routeTree.gen.ts` is generated.
- `src/components/invoice-generator.tsx` — the editor shell: toolbar, MCP dialog, import/export, local draft, cloud load/save, and the `?print=1` print view.
- `src/components/invoice-form.tsx` / `invoice-preview.tsx` / `invoice-pdf.tsx` — form, live preview and `@react-pdf/renderer` output. Keep preview and PDF in sync by hand.
- `src/components/invoice-form-utils.ts` — line totals and date helpers (tested).
- `src/components/form/` — composed inputs (`address-fields`, `date-picker`, `period-range-picker`).
- `src/data/wilayah/*.json` — Indonesian province/region tables, one file per BPS province code, generated by `scripts/parse-wilayah.ts` from `wilayah.sql`. Regenerate rather than hand-editing entries. `countries.ts` is the country list.
- `src/lib/use-cloud-save.ts` — owner-authenticated optimistic cloud save (`PUT /api/invoice/:id`, Bearer token, rollback).
- `src/lib/og-url.ts` — OG image URLs on the public `og.bahrul.me` renderer.
- `src/data/sample-invoice.json` — sample document.
- `public/` — `robots.txt`, `sitemap.xml`, `llms.txt`, favicons.

## Backend

`MCP_API` in `invoice-generator.tsx` is `http://localhost:8788` in dev
(`apps/api` under `wrangler dev`) and `https://api.pilihpendidikan.com` in prod.
Users mint a personal token at `https://api.pilihpendidikan.com/connect`
(`MCP_URL`). `?invoice=<slug>` loads a saved invoice; `/invoice/<slug>.pdf` on
the API redirects to `?invoice=<slug>&print=1`.

## Shared UI

Imports from `@rulisme/ui/*`, which resolves to the built `dist/` at runtime —
build `packages/ui` first (the root `bun dev` / `bun run build` do). shadcn
config in `components.json`.

## Design system — Warp ("moonlit terminal")

Shared with `apps/cv` and `apps/portfolio` (`DESIGN.md`). The `@theme inline` typography tokens in `src/styles.css` must stay byte-identical to `apps/cv` (`bun run parity:typography`). Never hardcode hex or `text-[Npx]` in chrome.

- **Themes.** Light and dark via next-themes (`.dark` class, system theme by default); dark is canonical. `theme-color` is `#121212`.
- **Surfaces.** canvas `#121212` · banded `#1e1e1d` · card `#2f2f2f` · control `#383838` · floating `#40403f` (`--popover`). Text is warm off-white `#faf9f6` — never `#fff`.
- **Type.** Named Warp tokens; `text-xs` for chrome; weights 400/500 only.
- **Radius.** buttons/nav `4px`, cards/panels `8px`; buttons are never pill-shaped.
- **Accent discipline.** Gold/cobalt accents only in code/syntax and section headings. No shadows. Exception: the per-invoice `accentColor` (default `#f48120`) and the swatch presets in `invoice-form.tsx` are document content — the user's branding on the invoice — and stay raw hex.
- **Print exception.** The rendered invoice is a print artifact: `invoice-preview.tsx`, `invoice-pdf.tsx` and `.invoice-page` stay light and print-faithful (ink on white, Helvetica). The typography lint skips these files (`TYPOGRAPHY.md` § Exceptions).
